# Foto / poster dokter gigi

Lampiran gambar di percakapan belum merupakan file di direktori proyek.
Letakkan file asli yang Anda miliki di direktori ini dengan nama berikut:

- `drg-eka.jpg`
- `drg-hanif.jpg`
- `drg-irsyad.jpg`
- `drg-firda.jpg`
- `drg-linni.jpg`
- `drg-shania.jpg`
- `drg-isna.jpg`

Ekstensi `.jpeg`, `.png`, dan `.webp` juga didukung. Gunakan ekstensi huruf
kecil; jangan hanya mengganti ekstensi tanpa mengonversi format sebenarnya.
Nama tanpa awalan `drg-`, misalnya `eka.png`, juga didukung.

Poster akan tampil utuh agar nama, jadwal dan identitas pada materi tidak
terpotong. Klik poster untuk memperbesar. Kartu menggunakan bingkai krem,
aksen hijau yang senada dengan materi klinik, dan jadwal berbentuk teks yang
mudah dibaca di HP. Foto tidak diberi filter yang mengubah wajah.

Ketika file belum tersedia, kartu menampilkan inisial dan keterangan jujur,
bukan foto orang lain atau gambar rusak. Restart dev server jika file baru
belum terdeteksi; jalankan ulang `npm run build` sebelum deploy.

Dokter umum dr. Hamidi dan dr. Kirei, serta dokter estetika dr. Nadelia,
tidak dimasukkan ke halaman layanan gigi. Materi mereka dapat dipakai pada
halaman layanan umum terpisah setelah cakupan website disetujui klinik.
