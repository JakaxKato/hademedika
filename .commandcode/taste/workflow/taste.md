# Workflow

- Wants the agent to analyze the existing codebase/context first and only then execute changes; explicitly opens the task with "analisa terlebih dahulu lalu eksekusi" (analyze first, then execute). Confidence: 0.8
- Prefers iterative refinement of an existing codebase over a from-scratch rebuild; frames work as a "refinement pass, not a complete redesign" that preserves the strongest existing parts. Confidence: 0.75
- Favors scoped, reviewable improvements (small focused changes) rather than wholesale rewrites. Confidence: 0.6
- Wants commit history to look disciplined: split changes into multiple themed commits (one concern per commit) using conventional-commit prefixes (feat/chore/docs) with descriptive bodies, rather than a single lumped commit. Confidence: 0.7
- Prefers to run git operations (staging/committing) themselves: wants the agent to only provide the commit plan — the exact commands and commit messages — and explicitly declines having the agent execute them ("sisanya saya sendiri yg melakukan"). Confidence: 0.75
- Generally prefers to carry out the implementation/changes himself (including placing files and running commands), and asks the agent only for concrete step-by-step instructions rather than direct execution — e.g. when he already has the assets, he wants a guide for applying them ("cukup berikan instruksi saja … sisanya saya sendiri yg melakukan"). Confidence: 0.7
- Works on long-running projects that span multiple sessions and expects context/continuity to be preserved across them (explicitly asks the agent to "remember this session" so work can continue later). Confidence: 0.5
- Prefers convention-based, auto-detecting asset pipelines over manual wiring: wants to drop files (named by an agreed folder/naming convention, e.g. photos into `assets/images/doctors/`) and have the app pick them up and display them automatically, with no code changes needed on his side — expecting the agent to then run the build/verification. Willingly adopts the agreed convention when adding new assets ("sudah saya tambahkan ... dengan format yang anda sarankan"). Confidence: 0.7
