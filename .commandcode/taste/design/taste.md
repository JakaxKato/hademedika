# Design

- Dislikes generic AI-generated template aesthetics; prefers a restrained editorial design system with a single muted accent color, generous whitespace, and asymmetric composition. Excludes purple/blue "AI" gradients, excessive glassmorphism, excessive pills, uniform rounded cards, and three-column equal feature-card rows. Confidence: 0.7
- Expects accessibility and responsive rigor as a default: keyboard focus states, pressed/hover states, reduced-motion support, ~44px minimum touch targets, inline validation errors, and no horizontal overflow. Confidence: 0.65
- Values color/design consistency, e.g., keeping a single defined accent token instead of off-palette hues, and maintaining a consistent light direction in shadows (no pure black or pure white). Confidence: 0.6
